# Braille

A static site for turning text into Braille. Open it in a browser; there is no build step and no server.

## Pages

- `index.html` — home page
- `braille.html` — Braille converter
- `notepad.html` — write text and convert it in the page
- `read.html` — document reader
- `upload.html` — upload a text file and download the converted result

Shared script and styles live in `braille.js` and `styles.css`.

## Run

Open `index.html` in a browser.
